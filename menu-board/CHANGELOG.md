# CHANGELOG

## [1.0.0] - 2026-10-01

### Added
- 메뉴판 편집 도구 첫 버전. 시프트표(`schedule-board`)의 구조(설정·문구·동작 분리, 저장, 인쇄, 이미지 미리보기, 데이터 이동)를 그대로 따름
- 앞면(キャスト・フード・カラオケ), 뒷면(アルコール・ノンアルコール), リモートメニュー를 탭으로 전환
- 메뉴판의 박스 하나 = 편집 칸 하나. 제목·품목·가격·메모를 한 칸에서 편집
- 리본 위 제목 수정 (글자 부분만 주변 색으로 메우고 다시 씀)
- 박스마다 메모 추가·삭제, 리모트 메뉴의 구분 장식 추가
- 품목 추가·삭제·순서 변경, 칸이 넘칠 때 자동 축소
- 인쇄 시 모든 페이지를 A4 한 장씩 출력
- 시프트표로 이동하는 링크 (저장하지 않은 변경이 있으면 저장할지 확인)
- 템플릿 이미지를 png로 통일
- 뒷면 목록에 가격 칸 (비우면 이름만), リキュール系는 박스 오른쪽 끝까지 사용
- セット 메뉴(1セット・お茶会セット・飲み放題) 탭
- 리본 위 영어 제목을 세리프체 + 가로 그라데이션 + 리본 곡선을 따라 휘게 표시
- 세트·앞면·뒷면 템플릿: 위쪽 장식(왼쪽 리본·오른쪽 찻잔·왕관 MENU)을 세 장 똑같이 맞추고, 메뉴 글자를 지운 빈 템플릿으로 바꾸고, 2110px 폭으로 키움
- 「画像を差し替え」: 페이지마다 템플릿 이미지를 이 기기에서만 임시로 바꿈 (IndexedDB)
