# Sweet Afternoon メニュー管理

가게 메뉴판 네 장(앞면: 캐스트·푸드·가라오케, 뒷면: 알코올·논알코올, 리모트 메뉴, 세트 메뉴)의 제목, 품목, 가격, 메모를 고쳐서 이미지로 저장하거나 인쇄하는 도구입니다. 화면은 모두 일본어이고, 시프트표(`schedule-board`)와 같은 방식으로 git 서버(GitHub Pages 등)에 올린 주소(https://…)로 열어서 씁니다.

## 사용법

1. 올려 둔 주소의 `menu-board/`를 Chrome, Edge, Safari 중 하나로 엽니다.
2. 위쪽 탭에서 「表（キャスト・フード）」「裏（ドリンク）」「リモート」「セット」 중 하나를 고릅니다.
3. 메뉴판의 글자나 제목을 누르면 그 박스의 편집 창이 뜹니다. 아래(PC에서는 오른쪽) 목록에서 바로 입력해도 됩니다. 메뉴판의 박스 하나가 편집 화면의 칸 하나입니다.
   - 「見出し」: 리본 위 제목(「Cast Menu」「ビール」 등)을 바꿉니다.
   - 가격은 입력한 그대로 나옵니다. 단위도 직접 씁니다. (예: `1200yen`, `時価`)
   - 뒷면 목록도 가격 칸이 있습니다. 비워 두면 이름만 나옵니다.
   - 「＋ 品目を追加」로 품목을 늘리고, 「↑」「↓」로 순서를 바꾸고, 「×」로 지웁니다.
   - 「＋ メモを追加」로 박스에 메모 한 줄을 넣습니다. 포스터에는 `— 메모 —` 모양으로 박스 맨 위에 나오고(Food는 원래 안내문 자리), 「×」로 다시 뺍니다.
   - 세트 메뉴는 박스마다 제목·가격·설명 줄을 각각 고치고, お茶会セット의 홍차 목록(♡)은 추가·삭제할 수 있습니다.
   - 리모트 메뉴는 「＋ 区切りを追加」로 품목 사이에 구분 장식을 넣을 수 있습니다.
   - 박스에 다 안 들어가면 줄 간격과 글자 크기가 자동으로 줄어듭니다. 박스마다 최대 줄 수가 있습니다(오른쪽 위 `5 / 10`).
4. 아래 버튼을 사용합니다.

| 버튼 | 동작 |
|---|---|
| 保存 | 브라우저(localStorage)에 저장. `Ctrl+S`로도 저장 |
| 印刷 | 모든 장을 A4 한 장씩 인쇄 |
| 画像プレビュー | 지금 탭의 PNG를 미리 보여주고, 「ダウンロード」로 내려받기. 휴대폰에서는 길게 눌러 사진에 저장 가능 |
| 初期内容に戻す | 지금 탭의 내용을 처음 메뉴(`js/config.js`)로 되돌림 |
| データ移行 | 다른 기기로 데이터 옮기기 (시프트표와 같은 방법, 파일 이름은 `menu-data_날짜.json`) |

- 위쪽 「シフト管理へ」로 시프트표로 갑니다(시프트표에는 「メニュー管理へ」). 저장하지 않은 변경이 있으면 저장하고 갈지, 버리고 갈지 묻습니다.
- 저장하지 않고 창을 닫으려 하면 경고가 나옵니다. 아이폰 홈 화면 추가, 저장 위치 주의 사항은 시프트표 README와 같습니다.

## 사진 임시로 바꾸기

급할 때, git 서버에 새 이미지를 올리기 전에 이 기기에서만 템플릿 이미지를 바꿔 쓸 수 있습니다.

1. 포스터 아래 「画像を差し替え」를 누르고 이미지(png, jpg)를 고릅니다.
2. 「仮の画像を使用中（この端末だけ）」가 표시되고, 새로고침해도 유지됩니다.
3. 원래대로 돌리려면 「元の画像に戻す」를 누릅니다.

- 이미지는 브라우저(IndexedDB)에 저장됩니다. 다른 기기나 브라우저에는 보이지 않고, 「データ移行」에도 들어가지 않습니다.
- 글자 위치는 원래 이미지 기준이라, 같은 디자인(같은 비율·배치)의 이미지여야 맞습니다. 비율이 다르면 경고가 나옵니다.
- 서버의 이미지를 정식으로 바꾼 뒤에는 「元の画像に戻す」를 눌러 두세요. 임시 이미지가 남아 있으면 그쪽이 계속 쓰입니다.

## 동작 원리

템플릿 이미지(글자가 들어간 완성본)를 깔고, 원래 글자를 지운 뒤 입력한 내용을 다시 씁니다.

- 품목 자리: 주변 바탕색으로 덮습니다.
- 리본 위 제목: 글자 부분만 골라 주변 색으로 메웁니다. 리본의 그라데이션과 테두리가 그대로 이어집니다.
- 리모트 메뉴: 품목 칸을 모두 지우고 둥근 칸을 다시 그립니다. 리본 아이콘과 구분 장식은 원래 이미지에서 잘라 씁니다.

그림(리본, 아이콘, 꽃 등)은 바꿀 수 없습니다.

## 파일 구조

```
index.html          화면 틀 (문구는 js/texts.js에서 채움)
css/style.css       화면·인쇄 스타일
assets/             템플릿 이미지 (menu-front.png, menu-back.png, menu-remote.png, menu-set.png)
js/config.js        설정 (색, 글꼴, 박스 위치, 처음 메뉴, 이미지 경로)
js/texts.js         화면 문구
js/app.js           동작 전체
```

## 자주 바꾸는 설정 (`js/config.js`)

| 항목 | 설명 |
|---|---|
| `fonts` | 글꼴. `mincho`(일본어), `title`(리본 위 영어 제목), `serif`(리모트 메뉴 가격), `bodoni`(세트 메뉴 큰 가격) |
| `title.gradient` / `arc` / `condense` | 영어 제목의 그라데이션 색(왼쪽→가운데→오른쪽), 곡선 높이, 글자 폭 |
| `inkColor` / `leaderColor` / `bulletColor` | 글자색 / 이름과 가격 사이 점선 색 / 목록 앞 반짝이 색 |
| `outputWidth` | 만들어지는 이미지의 가로 크기(px). 클수록 인쇄가 선명 |
| `pages[].image` | 페이지별 템플릿 이미지 경로 |
| `sections[].items` / `title.text` / `note.text` | 처음 메뉴·제목·메모. 「初期内容に戻す」를 누르면 이 내용으로 돌아감 |
| `sections[].maxItems` | 박스에 넣을 수 있는 최대 줄 수 |
| `sections[].label` | 편집 화면에 나오는 박스 이름 |
| `title.fontSize` | 제목 글자 크기 |

`areas`(글자 영역), `erase`(지울 영역), `lineHeight`, `capsule`, `iconRect`, `dividerRect`는 템플릿 이미지에 맞춰 잰 값입니다. 템플릿 디자인을 바꿀 때만 고칩니다.

페이지(탭)를 늘리려면 `pages`에 항목을 추가하고, 탭 이름은 `js/texts.js`의 `pageTabs`에 넣습니다.

## 템플릿 이미지 교체

이미지는 모두 png로 맞춰 두었습니다.

- **같은 디자인의 고해상도 원본으로 바꿀 때**: `assets/`의 파일을 덮어쓰거나 `image` 경로만 바꿉니다. 좌표는 `template` 크기 기준이라 비율이 같으면 그대로 맞습니다. 지금 이미지는 가로 1000px 정도라 인쇄하면 그림이 조금 흐릴 수 있으니, 원본이 있으면 바꾸는 것을 권장합니다.
- **글자가 없는 빈 템플릿이 있을 때**: 그대로 바꾸면 됩니다. 지울 글자가 없어도 눈에 띄지 않습니다.
- **배치가 다른 디자인으로 바꿀 때**: `template`, `areas`, `erase` 등을 새 이미지에 맞춰 다시 잽니다.
