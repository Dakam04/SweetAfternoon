# CHANGELOG

## [1.8.0] - 2026-09-29

### Added
- `js/texts.js`: 화면·포스터·확인 창·상태 메시지 문구를 한 곳에 모음. `index.html`은 `data-text` 속성으로 문구를 받음
- `assets/template.webp`: 템플릿 이미지를 일반 이미지 파일로 분리
- 설정 `templateImage` (템플릿 이미지 경로)
- 파일로 직접 열어 이미지를 만들 수 없을 때 안내 메시지 표시

### Changed
- 배포 방식을 git 서버(https 주소)로 일원화

### Removed
- `js/template.js` (base64 이미지)
- `tools/build-single.js` (원파일 만들기)

## [1.7.0] - 2026-09-29

### Added
- 「データ移行」: 데이터 내보내기(JSON 파일, 휴대폰은 공유 창)와 가져오기(같은 날짜만 덮어쓰기)

## [1.6.0] - 2026-09-29

### Added
- 원파일 버전 `dist/shift-board.html`과 만드는 스크립트 `tools/build-single.js`
- 아이폰 홈 화면 추가용 메타 태그 (전체 화면 실행, 앱 이름)
- iOS 15 이하용 canvas `roundRect` 대체 구현

### Changed
- 터치 기기에서 입력칸 글자 크기를 16px로 고정 (iOS Safari 자동 확대 방지)
- 상단 바 여백에 노치·상태 표시줄 영역(safe area) 반영

## [1.5.0] - 2026-09-28

### Changed
- 주 선택을 탭 목록에서 「‹」「›」(한 주씩 이동), 「今週」(이번 주로), 「日付で移動」(날짜로 이동)으로 변경. 기간 제한 없음
- 현재 주 표시에 이번 주와의 거리 표기 추가 (예: 「(3週前)」)

### Removed
- 주 탭 목록과 설정 `pastWeeks`, `futureWeeks`

## [1.4.0] - 2026-09-28

### Added
- 지난 주 보기: 탭 범위를 설정(`pastWeeks`, `futureWeeks`)으로 조절. 기본 4週前〜来週
- 포스터 「拡大表示」 버튼
- 이미지 미리보기 확대·축소 (이미지 탭 또는 「拡大」 버튼, 원본 크기로 보고 스크롤)

### Changed
- 주 탭이 넘치면 가로 스크롤, 선택한 탭이 보이도록 자동 이동
- 이미지 미리보기 창 최대 폭 900px → 1100px
- 인쇄할 때 열려 있는 창(편집·미리보기)은 숨기고 포스터만 인쇄

## [1.3.1] - 2026-09-28

### Added
- 설정 `closedMessage` (휴무일 기본 메시지, 기본 공백). 날짜별 메시지가 비어 있을 때 사용

### Removed
- 하트 숫자 수정 기능 (「ハート」 입력칸). 하트에는 항상 날짜가 표시됨

## [1.3.0] - 2026-09-28

### Added
- 이미지 미리보기 창 (「画像プレビュー」): 저장될 PNG 확인 후 다운로드, 휴대폰은 길게 눌러 사진 저장
- 휴무 메시지를 날짜별로 입력 (「メッセージ（任意）」, 후보 선택 가능)

### Changed
- 휴무 메시지 기본값을 공백으로 변경. 메시지가 없으면 휴무 카드 글자를 가운데로 재배치
- 「前週をコピー」가 휴무 메시지도 함께 복사

### Removed
- 설정 `closedMessage` (날짜별 입력으로 대체, 후보는 `closedMessagePresets`)

## [1.2.1] - 2026-09-28

### Changed
- 근무 표시를 점선 방식(이름 왼쪽, 시간 오른쪽, 사이 점선)으로 되돌림
- 글자색을 카드 색(핑크/하늘색)에 맞춘 고정색으로 되돌림

### Removed
- 「文字色」 선택 기능과 설정 저장(`settingsKey`)

## [1.2.0] - 2026-09-28

### Added
- 휴무 이유 입력 (후보 선택 또는 직접 입력), 휴무 카드 디자인 (Holiday 문구, 바탕색, 점선 테두리, 안내 문구)
- 이벤트 입력, 카드 위쪽 이벤트 띠 표시
- 포스터 글자색 선택 (プラム, コーラル, レッド)
- 이름·휴무 이유·이벤트 입력칸을 콤보박스(직접 입력 + 터치하면 후보 목록)로 변경

### Changed
- 화면 문구를 모두 일본어로 변경
- 포스터 글꼴을 명조 굵은체로, 근무 표시를 가운데 정렬로 변경 (점선 리더 제거)
- 태블릿 가로·세로, 휴대폰 화면 배치와 터치 영역 크기 조정
- 「前週をコピー」가 휴무 이유도 함께 복사

### Removed
- 이름 자동완성용 `<datalist>` (콤보박스로 대체)

## [1.1.0] - 2026-09-28

### Added
- 포스터의 칸을 누르면 그날을 수정하는 모달 창
- 하트 숫자 직접 수정 (비워 두면 날짜 자동)

## [1.0.0] - 2026-09-28

### Added
- 주 단위 스케줄 입력 (오늘 기준 전주, 이번 주, 다음 주)
- 템플릿 포스터 실시간 미리보기 (하트에 날짜, 점선 리더로 이름과 시간 표시, 휴무 표시)
- 저장(localStorage), 인쇄(포스터만 A4), 이미지 저장(PNG), 전주 복사, 이 주 비우기
- 이름 자동완성, 저장 안 된 변경 경고, Ctrl+S 저장
- 휴대폰 화면 대응
