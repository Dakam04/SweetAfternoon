# DEVLOG-20260928-005 하트 수정 제거, 기본 메시지 설정

## 요청
- 「ハート」 입력칸(하트 숫자 수정) 삭제
- `closedMessage` 설정을 기본 공백으로 두고 수정 가능하게

## 조치
- 하루 데이터에서 `heart` 필드 제거. 하트에는 항상 날짜를 그린다. 이전에 저장된 `heart` 값은 읽을 때 무시되고, 다음 저장 때 빠진다.
- `config.js`에 `closedMessage: ''` 복원. 휴무 카드 메시지는 「날짜별 메시지 → 설정 기본 메시지 → 없음」 순서로 정한다.
- 날짜별 메시지 입력칸의 안내 글자(placeholder)는 기본 메시지가 있으면 그 값을 보여준다.

## 검증
- 입력 화면·편집 창에 하트 입력칸이 없음, 이전 heart 값이 있는 데이터를 열어도 하트에 날짜가 표시됨, 저장 후 heart 필드 제거 확인.
- closedMessage 공백: 메시지 미표시. 값 설정: 모든 휴무일에 표시, 날짜별 입력이 있으면 그 값 우선.
