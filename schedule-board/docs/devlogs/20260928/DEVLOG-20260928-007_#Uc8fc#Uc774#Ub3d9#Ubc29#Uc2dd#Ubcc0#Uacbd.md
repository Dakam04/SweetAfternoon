# DEVLOG-20260928-007 주 이동 방식 변경

## 요청
탭 개수를 늘리지 말고, 언제든(어느 주든) 볼 수 있게.

## 조치
- 탭 목록(`renderTabs`)과 설정 `pastWeeks`/`futureWeeks` 삭제.
- `renderWeekNav()`: 현재 주 제목, 기간, 이번 주와의 거리(`relativeWeekLabel`), 「今週」 버튼 활성 여부, 날짜 입력값을 갱신.
- 「‹」「›」는 `weekOffset`을 ±1, 「今週」는 0으로 설정. 범위 제한 없음.
- 「日付で移動」: 고른 날짜가 속한 주의 오프셋을 `weekOffsetOf()`로 계산 (UTC 기준 날짜 차이로 계산해 서머타임 영향 없음).
- 데이터는 원래 날짜 키로 저장되므로 저장 구조 변경 없음.

## 검증
- 이전 10회 → 7/20〜7/26(10週前), 날짜 2025-12-25 → 12/22〜12/28(40週前), 2027-03-01 → 3/1〜3/7(22週後), 다음 → 3/8〜, 今週 → 9/28〜10/4, 今週 버튼은 이번 주일 때 비활성.
- PC, 태블릿 세로(820px), 휴대폰(390px) 배치 확인.
