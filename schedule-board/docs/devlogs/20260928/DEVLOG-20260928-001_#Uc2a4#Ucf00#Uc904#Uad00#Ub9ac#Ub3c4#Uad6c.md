# DEVLOG-20260928-001 스케줄 관리 도구

## 목적
시프트표 템플릿(7칸, 한 칸이 하루)을 주 단위로 채워 인쇄하거나 이미지로 저장하는 내부 도구.

## 구성 결정
- 서버 없이 `index.html` 직접 열기로 동작. 스크립트는 ES 모듈 대신 일반 `<script>`를 사용 (file:// 에서 모듈 로딩이 막히기 때문).
- 포스터는 canvas 하나로만 그린다. 미리보기, 인쇄, 이미지 저장이 같은 그림을 쓰므로 배치 로직이 한 곳에만 있다.
- 템플릿 이미지를 base64로 스크립트에 넣음. 파일로 불러오면 file:// 에서 canvas가 오염되어 PNG 내보내기가 막히기 때문.
- 데이터는 날짜 키(`YYYY-MM-DD`)별로 저장. 주 개념은 화면에서만 계산하므로 주 시작 요일을 바꿔도 데이터가 깨지지 않는다.
- 빈 날은 저장하지 않아 데이터가 쌓이지 않게 함.

## 검증
- file:// 로 열어 입력 → 저장 → 새로고침 후 유지, PNG 내려받기, 전주 복사(다음 주 탭), 긴 이름 자동 축소, 휴무 표시 확인.
- 인쇄: A4 PDF 출력 시 포스터만 한 장으로 나오는 것 확인.
- 화면: 폭 1400px / 390px 캡처로 확인.
