# DEVLOG-20260928-006 지난 주 보기, 포스터 확대

## 요청
- 몇 주 전까지 볼 수 있게
- 포스터 이미지가 작아서 크게 볼 수 있게

## 조치
- 고정 3개 탭(`WEEK_OFFSETS`) 대신 설정 `pastWeeks`(기본 4), `futureWeeks`(기본 1)로 탭을 만든다. 이름은 先週·今週·来週·再来週, 나머지는 「n週前」「n週後」.
- 탭이 넘치면 가로 스크롤. 다시 그릴 때 선택한 탭을 가운데로 스크롤.
- 포스터 오른쪽 위에 「拡大表示」 버튼 → 기존 이미지 미리보기 창을 연다.
- 미리보기 창: 이미지를 감싸는 스크롤 영역(`#image-viewport`) 추가. 이미지 탭 또는 「拡大」 버튼으로 원본 크기(2535px) ↔ 전체 보기 전환. 확대할 때 누른 지점이 가운데 오도록 스크롤.
- 인쇄 시 「拡大表示」 버튼은 숨김.

## 검증
- 탭 6개(4週前〜来週) 표시, 4週前 선택 시 8/31〜9/6 주 표시.
- PC: 확대 버튼 → 미리보기, 이미지 클릭 시 원본 크기·클릭 지점 스크롤, 「全体を表示」로 복귀.
- 휴대폰(390px): 탭 가로 스크롤과 今週 자동 위치, 미리보기 확대 확인. 인쇄 PDF에 버튼 미표시.
