# DEVLOG-20260928-004 이미지 미리보기, 휴무 메시지

## 요청
- 사진 미리보기 추가
- 휴무 카드의 「またのお帰りをお待ちしております」를 기본 공백으로, 수정 가능하게

## 조치
- 「画像を保存」을 「画像プレビュー」로 바꾸고, 누르면 저장될 PNG를 `<dialog>`에 보여준다. 창 안의 「ダウンロード」 링크가 같은 PNG를 내려받는다. 창을 닫으면 임시 URL(`URL.createObjectURL`)을 해제한다.
  - 휴대폰(특히 iOS)은 파일 다운로드보다 이미지 길게 누르기 → 사진 저장이 편해서 안내 문구를 넣었다.
- 하루 데이터에 `closedMessage` 추가 (기본 ''). 입력칸은 휴무일에만 보이며 콤보박스(후보 `closedMessagePresets` + 입력 이력).
- 메시지가 없으면 휴무 카드 글자 묶음을 24px 내려 가운데를 맞춘다.
- 이전 데이터는 `emptyDay()` 기본값과 합쳐지므로 기존 휴무일은 메시지 없이 표시된다.

## 검증
- 이전 형식 데이터(closedMessage 없음) 로드, 메시지 후보 선택·직접 입력·저장, 미리보기 표시(원본 2535px), 다운로드, 닫을 때 임시 URL 해제, 휴대폰 폭(390px) 표시 확인.
