# DEVLOG-20260929-004 위치 조정 가이드, 레이아웃 설정

## 요청
템플릿 위 글자 위치를 고치기 쉽게. (1) 가이드 표시 모드 (2) 코드 안 고정값을 설정으로.

## 조치
- 가이드 표시: 주소에 `?guide`가 있으면 `SHOW_GUIDE`가 켜지고, `drawPoster()` 끝에서 `drawGuide()`가 카드별 글자 영역(점선), 하트 중심(십자), 좌표 라벨을 그린다. 시작할 때 상태 줄에 안내(`texts.js`의 `guideOn`).
  - 영역 라벨은 이벤트 띠를 가리지 않도록 영역 아래쪽에 둔다.
  - 저장 이미지에는 넣지 않는다: `openImagePreview()`에서 가이드 없이 다시 그린 뒤 `toBlob()`을 호출하고, `finally`에서 가이드를 다시 그린다. `toBlob()`은 호출 시점의 그림을 복사하므로 곧바로 다시 그려도 저장 이미지에 영향이 없다.
  - 인쇄는 화면 canvas를 그대로 쓰므로 가이드가 들어간다(README에 안내).
- `drawPoster(withGuide = SHOW_GUIDE)`로 인자를 받게 되어, 글꼴 로드 후 `.then(drawPoster)`가 Promise 결과(배열)를 `withGuide`로 넘기는 문제가 생긴다. `.then(() => drawPoster())`로 변경.
- 설정 `layout`: `heartNumber`(size 76, maxWidth 110, offsetY 4), `dateLabel`(size 34, offsetY -12), `eventRibbon`(height 66, top 8, size 36, gap 16), `rows`(maxSize 44, lineHeight 1.6), `closed`(headingSize 34, reasonSize 66, messageSize 26). 모두 기존 코드 값 그대로.
  - 이벤트 띠 아래 남는 영역 계산 `ribbonH + 24`를 `top + height + gap`(8 + 66 + 16 = 90)으로 바꿨다. 결과는 같다.
  - 휴무 카드 안의 세로 위치(중심 기준 -88, +58, +110)와 좌우 여백(w - 40 등)은 코드에 남겼다.

## 검증 (Chromium, Playwright)
- 수정 전·후에 같은 입력(근무 3명, 휴무+메시지, 이벤트+근무, 이벤트+휴무)을 넣었다. 포스터 canvas 픽셀 해시가 같았다.
- `?guide`: 가이드가 표시되고, 画像プレビュー 이미지 해시는 가이드 없는 화면과 같았다. 미리보기를 닫은 뒤 화면에는 가이드가 다시 표시됐다. 스크립트 오류 없음.
- 실제 Safari는 미확인.
