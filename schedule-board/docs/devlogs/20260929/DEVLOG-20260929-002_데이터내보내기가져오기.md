# DEVLOG-20260929-002 데이터 내보내기·가져오기

## 요청
다른 휴대폰으로 데이터를 넘길 수 있게 내보내기·가져오기 추가

## 조치
- `cleanSchedule()`: 저장용 정리 로직을 `saveSchedule()`에서 분리해 내보내기와 같이 쓴다. `saveSchedule()`은 성공 여부를 반환.
- 내보내기 `exportData()`: `{ format: 'sweet-afternoon-shift', version: 1, exportedAt, schedule }` JSON.
  - 저장 안 한 변경이 있으면 저장할지 확인 후 진행.
  - 터치 기기이고 파일 공유를 지원하면 공유 창(`navigator.share`), 아니면 파일 다운로드. 공유 취소(AbortError)는 무시, 그 밖의 실패는 다운로드로 대체.
- 가져오기 `importData()`: 5MB 제한, `format` 확인, 날짜 키 형식 확인, `normalizeDay()`로 필드 타입 정리·인원 수 제한.
  - 같은 날짜만 덮어쓰고 나머지는 유지(병합). 확인 창에 날짜 수와 규칙 표시. 가져온 뒤 즉시 저장.
- 하단 「データ移行」 버튼 → 설명과 두 버튼이 있는 창.

## 검증 (원파일, iPhone 13 에뮬레이션)
- 기기 A: 저장 안 한 변경 확인 창 → 저장 후 3일분 내보내기.
- 기기 B: 잘못된 JSON은 오류 메시지. 올바른 파일은 확인 창 후 병합(같은 날짜 덮어씀, 다른 날짜 유지), 즉시 저장, 화면 반영.
- 공유 창(navigator.share)은 에뮬레이션에서 지원되지 않아 다운로드 경로로 확인. 실제 아이폰 공유 창은 미확인.
