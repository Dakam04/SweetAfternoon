# DEVLOG-20260929-001 아이폰용 원파일

## 요청
아이폰에서도 쓸 수 있는 HTML 원파일 (사용자 v1.5.1 기준)

## 조치
- `tools/build-single.js`: index.html의 CSS 링크를 `<style>`로, 스크립트 3개를 body 끝 인라인 `<script>`로 바꿔 `dist/shift-board.html` 생성. 인라인 스크립트에는 defer가 적용되지 않아 body 끝에 둔다. 교체 대상 태그가 없으면 오류로 멈춘다.
- 아이폰 대응
  - 입력칸 16px 고정(`pointer: coarse`): iOS Safari는 16px 미만 입력칸에 포커스하면 화면을 확대한다.
  - `viewport-fit=cover` + 상단 바 `env(safe-area-inset-*)` 여백: 홈 화면 전체 화면 실행 시 노치 영역 회피.
  - 홈 화면 추가용 메타 태그.
  - canvas `roundRect` 대체 구현: Safari 15 이하에는 없어서 휴무 카드·이벤트 띠를 그리다 오류가 난다.
- 원파일은 외부 파일 없이 동작. 글꼴(Shippori Mincho)만 인터넷에서 불러오며, 없으면 기기의 명조체로 대체.

## 검증
- 원파일만 빈 폴더에 두고 Chromium의 iPhone 13 에뮬레이션(터치, 390px)으로 확인: 입력칸 16px, 포스터 탭 → 편집 창, 콤보박스 후보, 저장 후 새로고침 유지, 확대 보기, 다운로드.
- 실제 Safari(WebKit)는 샌드박스에서 설치할 수 없어 미확인.
