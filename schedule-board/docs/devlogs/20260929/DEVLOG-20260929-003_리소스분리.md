# DEVLOG-20260929-003 리소스 분리 (이미지, 문구)

## 요청
이미지와 문구를 바꾸기 쉽게 분리. 원파일 만들기(`tools/`)는 제거. 배포는 git 서버로만 한다.

## 조치
- 템플릿 이미지: `js/template.js`의 base64를 디코딩해 `assets/template.webp`(2535×2662, 원본과 같은 바이트)로 저장. `js/template.js` 삭제.
  - `config.js`에 `templateImage: 'assets/template.webp'` 추가, `loadTemplate()`이 이 경로를 읽는다.
- 문구: `js/texts.js`(`window.BOARD_TEXTS`)에 화면·포스터·확인 창·상태 메시지 문구를 모음.
  - `index.html`은 문구 대신 `data-text`(글자), `data-text-label`(aria-label), `data-text-alt`(alt)를 갖고, `applyTexts()`가 시작할 때 채운다. `<title>`도 여기서 설정.
  - 숫자가 들어가는 문구(주 제목, 몇 주 전/후, 읽기·쓰기 건수, 이벤트 띠)는 함수로 둔다.
  - 휴무 스위치는 `innerHTML` 대신 요소를 만들어 문구를 `textContent`로 넣는다.
  - 남긴 것: `console.error` 개발용 메시지, 장식 기호(♡ ▾ ×), 홈 화면 앱 이름 메타 태그, `config.js`의 휴무 문구·후보·요일 표기.
- 이미지 만들기 실패 처리: `file://`로 열면 canvas가 오염되어 `toBlob()`이 SecurityError를 던진다. `openImagePreview()`에서 잡아 로그를 남기고 안내 문구(`imageBlocked`)를 표시. 콜백은 `showImagePreview()`로 분리.
- `tools/build-single.js` 삭제. README에서 원파일·PowerShell 변환 안내를 지우고 git 서버 기준으로 수정.

## 검증 (Chromium, Playwright)
- 수정 전·후를 각각 http로 띄워 같은 입력(근무 2명, 휴무+메시지, 이벤트) 후 비교: 포스터 canvas 픽셀 해시 동일, 버튼·라벨·placeholder·aria-label·주 제목·「(今週)」「(先週)」·확대 버튼 문구·상태 메시지 동일. 빈 `data-text` 없음.
- http: 画像プレビュー 창 열림, 拡大 ↔ 全体を表示 전환, 저장 정상.
- file://: 입력·저장 정상, 画像プレビュー는 SecurityError를 잡아 안내 문구 표시(예외가 밖으로 나가지 않음).
- 글꼴 요청은 테스트에서 차단(오류 로그 1건은 이것). 실제 Safari는 미확인.
