# Sweet Afternoon シフト管理

가게 내부에서 쓰는 주간 시프트표 작성 도구입니다. 화면은 모두 일본어이고, 서버 없이 `index.html`을 브라우저로 열면 바로 동작합니다. PC, 태블릿, 휴대폰에서 모두 쓸 수 있습니다.

## 사용법

1. `index.html`을 Chrome, Edge, Safari 중 하나로 엽니다.
2. 위쪽 「‹」「›」로 한 주씩 이동합니다. 기간 제한 없이 과거·미래 어느 주든 볼 수 있습니다. 「今週」를 누르면 이번 주로 돌아오고, 「日付で移動」에서 날짜를 고르면 그 날짜가 들어 있는 주로 바로 이동합니다. 주는 오늘 날짜를 기준으로 자동 계산되고, 주 표시 아래에 「(3週前)」처럼 이번 주와의 거리가 나옵니다.
   - 포스터 오른쪽 위 「拡大表示」를 누르면 포스터를 크게 볼 수 있습니다. 창 안에서 이미지를 누르면 원본 크기로 확대되고, 다시 누르면 전체 보기로 돌아옵니다.
3. 포스터의 칸을 누르면 그날의 편집 창이 뜹니다. 아래(PC에서는 오른쪽) 목록에서 바로 입력해도 됩니다.
   - 하트 안의 숫자는 날짜가 자동으로 들어갑니다.
   - 「お休み」: 켜면 근무 입력 대신 「お休みの理由」와 「メッセージ（任意）」가 나옵니다. 이유는 定休日, 臨時休業 등 후보에서 고르거나 직접 입력하고, 비워 두면 「お休み」로 표시됩니다. 메시지는 기본으로 비어 있고, 입력한 날에만 카드 아래쪽에 작게 표시됩니다. 모든 휴무일에 같은 메시지를 쓰려면 설정의 `closedMessage`에 넣습니다.
   - 「イベント」: 입력하면 카드 위쪽에 띠로 표시됩니다.
   - 이름 칸: 누르면 지금까지 입력한 이름 목록이 나옵니다. 글자를 치면 목록이 좁혀지고, 목록에 없는 이름은 그대로 입력하면 됩니다.
4. 아래 버튼을 사용합니다.

| 버튼 | 동작 |
|---|---|
| 保存 | 브라우저(localStorage)에 저장. `Ctrl+S`로도 저장 |
| 印刷 | 포스터만 A4 한 장으로 인쇄 |
| 画像プレビュー | 저장될 PNG를 미리 보여주고, 「ダウンロード」로 내려받기. 휴대폰에서는 미리보기 이미지를 길게 눌러 사진에 저장 가능 |
| 前週をコピー | 바로 앞 주의 근무와 휴무를 이 주에 복사 (이벤트는 복사하지 않음) |
| この週をクリア | 이 주의 입력 내용 삭제 |
| データ移行 | 다른 기기로 데이터 옮기기 (아래 「다른 기기로 옮기기」 참고) |

저장하지 않고 창을 닫으려 하면 경고가 나옵니다.

## 아이폰에서 쓰기

`dist/shift-board.html`은 모든 파일(화면, 스타일, 설정, 템플릿 이미지, 동작)을 하나로 합친 파일입니다.

1. 이 파일을 웹 서버에 올립니다. (예: 홈페이지 서버의 `public/` 폴더, GitHub Pages, Netlify Drop 같은 무료 정적 호스팅)
   - 아이폰 「ファイル」 앱에서 파일을 바로 열면 미리보기로만 열려서 버튼이 동작하지 않을 수 있습니다. 반드시 Safari에서 주소(https://…)로 여세요.
2. Safari로 연 뒤 공유 버튼 → 「ホーム画面に追加」를 누르면 앱처럼 쓸 수 있습니다.
3. 이미지는 「画像プレビュー」에서 이미지를 길게 눌러 「写真に追加」로 저장하는 방법이 가장 확실합니다.

**아이폰 저장 주의**
- 저장 내용은 기기와 브라우저마다 따로입니다. PC에서 입력한 시프트는 아이폰에 보이지 않습니다.
- 홈 화면에 추가한 앱과 Safari 탭은 저장 공간이 서로 다릅니다. 한쪽만 정해서 쓰세요.
- Safari 탭으로만 쓰면, 7일 넘게 그 사이트를 열지 않았을 때 iOS가 저장 내용을 지울 수 있습니다. 홈 화면에 추가해서 쓰는 것을 권장합니다.

## 다른 기기로 옮기기

1. 지금 쓰는 기기에서 「データ移行」 → 「データを書き出す」를 누릅니다.
   - 휴대폰: 공유 창이 뜨면 AirDrop, LINE, メール 등으로 보냅니다.
   - PC: `shift-data_날짜.json` 파일이 내려받아집니다.
2. 옮길 기기에서 이 화면을 열고 「データ移行」 → 「データを読み込む」로 받은 파일을 고릅니다.
3. 같은 날짜는 읽어 온 내용으로 덮어쓰고, 나머지 날짜는 그대로 남습니다. 읽어 오면 바로 저장됩니다.

- 저장하지 않은 변경이 있으면 내보내기 전에 저장할지 묻습니다.
- 「データを書き出す」로 만든 파일만 읽어 옵니다. 다른 파일을 고르면 오류 메시지가 나옵니다.
- 백업용으로도 쓸 수 있습니다. 가끔 내보내 두면 휴대폰을 바꾸거나 데이터가 지워졌을 때 되살릴 수 있습니다.

### 원파일 다시 만들기

`css`, `js`, `index.html`을 고친 뒤에는 원파일도 다시 만들어야 반영됩니다. Node.js가 설치된 PC에서 프로젝트 폴더에 들어가 아래를 실행합니다.

```
node tools/build-single.js
```

## 주의

- 저장 위치는 **지금 쓰는 브라우저**입니다. 다른 PC나 휴대폰, 다른 브라우저에서는 보이지 않습니다.
- 브라우저의 사이트 데이터를 지우면 시프트도 함께 지워집니다.
- 폴더 위치를 옮기면 브라우저가 다른 사이트로 인식해 저장 내용이 보이지 않을 수 있습니다.
- 글꼴(Shippori Mincho)은 인터넷에서 불러옵니다. 오프라인에서는 기본 명조체로 그려집니다.

## 파일 구조

```
index.html          화면
css/style.css       화면·인쇄 스타일
js/config.js        설정
js/app.js           동작 전체
js/template.js      템플릿 이미지 (base64)
tools/build-single.js  원파일 만들기
dist/shift-board.html  원파일 결과물 (아이폰·배포용)
```

## 자주 바꾸는 설정 (`js/config.js`)

| 항목 | 설명 |
|---|---|
| `weekStartsOn` | 주 시작 요일. 0=일, 1=월 … 6=토 |
| `maxRows` | 하루 최대 인원 (기본 6) |
| `closedLabel` | 휴무 이유를 비웠을 때의 문구 (기본 「お休み」) |
| `closedMessage` | 휴무일 기본 메시지 (기본 공백 = 표시 안 함). 날짜별로 입력한 메시지가 우선 |
| `closedPresets` | 휴무 이유 후보 |
| `closedMessagePresets` | 휴무 메시지 후보 |
| `inkColors` | 카드 색(핑크/하늘색)별 글자색 |
| `toneColors` | 카드 색. 휴무 카드 바탕에 사용 |
| `cards` | 템플릿에서 하트와 글자 영역의 위치(px). 템플릿 이미지를 바꿀 때만 수정 |

## 템플릿 이미지 교체

템플릿은 `js/template.js` 안에 글자(base64)로 들어 있습니다. 파일을 직접 열어도 이미지 저장이 되도록 하기 위해서입니다.
새 이미지로 바꿀 때는 이미지 파일이 있는 폴더에서 아래 명령을 실행하고, 결과를 `js/template.js`로 덮어씁니다.

PowerShell:
```powershell
$b = [Convert]::ToBase64String([IO.File]::ReadAllBytes("template.png"))
"window.TEMPLATE_IMAGE = 'data:image/png;base64,$b';" | Set-Content -Encoding UTF8 js\template.js
```

이미지 크기나 카드 배치가 달라지면 `js/config.js`의 `template`과 `cards` 값도 맞춰야 합니다.
